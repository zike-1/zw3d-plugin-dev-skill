# 示例便签

这是一个不修改模型的可保存便签。它演示标准图标、固定入口、设置保留、旧设置迁移以及取消／保存失败处理。

工具箱启动 `ArtNotes.exe`，并传递该命令的固定 `arguments`。

源码不包含 SDK 安装路径。DLL 从自己的模块路径、EXE 从自己的程序路径确定目录，
不要用当前工作目录查找随包资源。

正常使用编辑文字并点“保存便签”，设置写入框架提供的`ZW_PLUGIN_DATA_DIR`，不使用当前工作目录。关闭时可保存、放弃或取消关闭；未知设置格式不会被编辑器覆盖。`settings.txt`使用`ZWN1`格式标记及UTF-8文本；旧`note.txt`迁入新格式时保留原文件。普通卸载保留这些文件，彻底清理才删除。

1.1.1修复：Esc进入关闭流程，未保存修改会询问；只有点击保存或在关闭提示中明确选择保存才写入。保存控件不使用Windows的`IDOK`／`IDCANCEL`编号，并校验点击来源。窗口大小图标使用构建器生成的应用图标资源101，与第一个命令PNG一致。

仅在测试时传入`/probe=<绝对日志路径>`写入命令标记；`/self-test=<绝对日志路径>`必须配合全新的隔离`ZW_PLUGIN_DATA_DIR`，测试中文保存及迁移，发现已有设置就拒绝。测试参数不在普通按钮中使用。

修改 ID、prefix、文件名、导出函数名和命令名时应同步修改。一个包只能声明自己的
命令；界面、安装、升级和卸载由共用工具箱处理。

使用工具包的`tools/build_plugin.py`并传入本示例目录；工具包位于源码仓库根目录或独立技能的`assets/kit/`。不要把SDK头文件或库复制到插件包。
