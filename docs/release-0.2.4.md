# zw3d-plugin-dev v0.2.4 — 扩展工具与框架维护修复

发布日期：2026-10-08。目标：Windows x64 / 中望3D 2027 插件开发技能。

## 本次更新

- **功能区改名**：界面显示名称由“小插件”统一改为“扩展工具”；管理入口“插件管理”，管理器窗口“扩展工具管理器”。内部`ZwPluginHubPage`、插件 ID 和安装协议保持不变。
- **MinGW 编译环境**：使用 `--toolchain` 时仅在构建子进程 PATH 中配置工具链，并增加前置工具探测与清晰错误提示，无需更改系统/用户 PATH。
- **安装互斥锁**：在显示安装或管理器维护结果弹窗前释放事务互斥锁，防止弹窗保持打开时阻塞其他安装操作。
- **框架升级为 1.1.4**：技能 0.2.4 随包携带冻结的 `ZwPluginHub.dll` 与 `HubManager.exe`；历史 `runtime/1.1.3` 保留不变。
