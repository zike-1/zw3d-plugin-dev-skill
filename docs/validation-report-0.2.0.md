## 本轮实现

| 要求 | 实现与边界 |
| --- | --- |
| 框架可持续升级 | 独立版本1.1.0、兼容协议1、哈希校验。协议1旧安装器复用兼容新框架，不降级覆盖；同版本不同内容拒绝。运行中暂存、宿主关闭后外部更新程序持锁提交，失败保留恢复记录。更高的待更新框架不会被较旧请求覆盖。 |
| 卸载目标准确 | 改安装位置立即清空旧列表和选择，禁用卸载；执行前再次检查列表所属路径。 |
| 坏登记隔离 | 管理器单独显示坏记录，日常加载跳过坏记录并加载正常插件。修改安装状态仍严格校验；无法恢复的安装事务不能被假装成功。 |
| 完整版本一致性 | 规范化清单身份、文件集合和内容一起冻结。图标、文字、命令与资源变更均增加版本；主机API检查不算业务内容变化。同版本重复安装保持文件内容和菜单排序不变；旧版本不能覆盖待安装的新版本。 |
| 图标 | 清单支持PNG与简短提示，验证分块、CRC和解压尺寸；框架提供默认图标，独立安装／更新／移除，不覆盖其他插件。 |
| 管理界面 | 待装名称版本、当前到目标版本、待安装／更新／卸载区别、最近启动加载结果、取消待处理、查看日志；默认保留数据，切换选择重置清理勾选。只读打开不提权，修改时请求权限。支持窗口重排、Tab导航与系统DPI缩放。 |
| 完整示例 | 便签可编辑和保存，关闭可取消，未知格式不覆盖；UTF-8设置有格式标记，旧文本迁移保留原文件，同一账户避免重复编辑窗口。问候提供1.1.0蓝图标及1.1.1橙图标升级示例。 |
| 技能与规范 | 契约、schema、验证器、模板、两个示例、发行运行时与自包含技能同步；基础构建器支持递归CPP及资源脚本，复杂项目仍可提供预构建有效载荷。 |
