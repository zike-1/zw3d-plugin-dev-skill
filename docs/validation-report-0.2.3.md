# 0.2.3应用图标与Esc修复

日期：2026-10-04。用户回传0.2.2测试步骤全部通过，同时发现窗口通用图标及Esc误保存。该通过记录保留，本轮只修复两项并做限定复验。技能0.2.3、框架1.1.3、便签1.1.1；问候业务1.1.0／图标更新1.1.1的冻结负载未改变。

## 原因与修改

- 原有PNG只投影到中望3D按钮。安装EXE、管理器和便签未嵌入并设置应用图标，窗口使用Windows通用图标。
- 便签保存按钮编号为2，与本机`winuser.h`的`IDCANCEL=2`相同。消息循环使用`IsDialogMessageW`，保存分支只比较编号，没有核对来源，因此Esc的取消命令误入保存分支。
- 构建器将校验过的首命令PNG封装为ICO资源101，保留原像素。安装器与源码构建EXE嵌入该图标；管理器使用工具箱PNG；窗口设置大小图标。预编译入口不被打包器静默重写。独立检查器沿图标组引用核对实际图像字节，而非只检查资源存在；旧框架1.1.2及更早安装器仍可按其历史契约检查。
- 保存控件改用1001，核对点击通知及真实控件来源。Esc进入关闭流程：无修改直接关闭；有修改则询问保存、放弃或取消。只有保存按钮或关闭确认的明确“是”才写入，数据格式、迁移与卸载保留规则不变。
- 技能、包契约、示例与验收补充窗口／任务栏／EXE图标，以及Esc和关闭确认的实际验收范围。
