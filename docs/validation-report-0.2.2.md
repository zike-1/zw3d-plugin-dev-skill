日期：2026-10-04。技能0.2.2，框架1.1.2，兼容协议1。范围：新增管理器的损坏登记恢复／隔离入口及可取消的等待重启队列，同步契约与技能，提供另一台电脑的独立安装测试包。示例业务版本与有效载荷沿用已验收的问候1.1.0、问候图标更新1.1.1、便签1.1.0。

结论：**PASS（限定源码、隔离安装及独立技能流程）；跨电脑与真实2027界面交互仍为未验证，整体交互验收为PARTIAL PASS。**本轮没有替换用户这台电脑的已安装工具箱，也没有启动或结束用户的CAD会话。

## 行为

- 活动登记损坏：先验证安装描述的身份、版本目录、全部索引文件大小／哈希、入口／图标和宿主接口；确认唯一来源后备份原登记并恢复。能读出原版本时只恢复该版本；完全丢失版本信息且存在多个历史版本时停止，不猜最新版本。
- 无完整来源、文件被修改或身份冲突：拒绝恢复，保留现场。用户可选择隔离：备份原登记，移出活动登记并重建菜单，保留程序版本与用户数据，再通过原安装包重装。
- 损坏待处理请求：不猜安装或卸载意图，整体备份请求及负载后隔离。有有效待处理请求时，活动登记修复会保留该请求；隔离前要求显式取消同插件请求，避免隔离后又隐式恢复。
- 运行中的宿主：维护请求进入等待队列，可取消。启动握手先维护、后正常安装，并再次核对原记录哈希；记录已变化时停止并保留待取消请求。
- 备份、登记、菜单及队列删除共用事务，普通失败回滚；操作前确认及恢复结果显示备份位置。修改安装位置会使原列表选择失效。正常登记不能执行修复或隔离。

本入口只处理活动／待处理登记，不宣称修好被删改的框架、业务程序、文件索引或任意外部文件。隔离不是普通卸载，也不清除设置或隔离备份；重新启用使用原安装包。跨Windows会话的并发锁和强制结束打包后的自动恢复尚未新增。
